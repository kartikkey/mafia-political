# RCA — deep-state-game (run 4dba5c6f-b6ea-4330-bcb7-d25e91896847)

## Summary
Initial deploy failed at **build_image** during the frontend compile. The app's own `vite.config.ts` uses Node built-ins that have no TypeScript types available, so the `tsc` step of `yarn build` fails with exit 2. This is a **source-code** issue, not a platform/manifest one.

## Failing step
`build_image` → `yarn build` → `tsc -p tsconfig.json && vite build`

## Exact error (Cloud Build, reproduced in sandbox)
```
vite.config.ts(3,31): error TS2307: Cannot find module 'node:url' or its corresponding type declarations.
vite.config.ts(21,20): error TS2591: Cannot find name 'process'. Do you need to install type definitions for node? Try `npm i --save-dev @types/node` and then add 'node' to the types field in your tsconfig.
error Command failed with exit code 2.
```

## Root cause
`frontend/vite.config.ts` imports `fileURLToPath` from `node:url` (line 3) and reads `process.env.PORT` (line 21). `frontend/tsconfig.json` `include`s `vite.config.ts`, so `tsc` type-checks it — but:
- `@types/node` is **not** in `frontend/package.json` devDependencies, and
- `tsconfig.json` sets `"types": ["vite/client"]`, which restricts type resolution and excludes Node's global/ambient types.

With no Node types in scope, `node:url` and `process` are undefined to the compiler → build fails.

## Fix (Code — E1 applies in the user repo)
Two edits in `frontend/`:
1. `frontend/package.json` → add `@types/node` to `devDependencies` (e.g. `"@types/node": "^20"`).
2. `frontend/tsconfig.json` → change `"types": ["vite/client"]` to `"types": ["vite/client", "node"]`.

## Verification (eph sandbox, run source at /app/scratch)
- Baseline `yarn build` reproduced the exact TS2307/TS2591 errors (exit 2).
- After `yarn add -D @types/node` + `types: ["vite/client", "node"]`, `yarn build` completed: `✓ built in 11.34s` / `Done`.
